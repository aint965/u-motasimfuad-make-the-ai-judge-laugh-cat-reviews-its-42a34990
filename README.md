A one-star review written by a house cat about its human, entered in the
[make.fun bounty "Make the AI Judge Laugh: Cat Reviews Its Human"](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990).

## The entry

> One star. He fills my bowl at 5am, then acts surprised when I yowl at 4:59. I am not early. He is late.

One funny single-line one-star review from a house cat about the human it lives
with — a specific complaint (the 5am food bowl), judged by cat standards, with
a sting in the last few words.

## How to run

Requires Node 22 or later. No dependencies, no network access.

```sh
node main.ts
```

This writes the review line to `/output/entry.txt` (a single line, no trailing
newline, under 200 characters).
